# Zentral Extended: handoff for the next session

Everything below is a **frozen snapshot**. Nothing here has been run inside Zen/Sine; all checks were done with Node tests, fake DOMs and static scans. Version in the tree is **3.1.3 (unreleased)**.

## 1. State of the work (done)

- README rewritten, full CC BY-NC-SA 4.0 `LICENSE`, `.github/FUNDING.yml` removed, JPG screenshots.
- Report-an-issue flow reworked (choose Extended repo or original base, log redaction, timeout, URL length guard).
- Bugs fixed: top/bottom resize handles at the window edge, RSS card behind the panel, Logger path key, dead `hide_detach_button` setting, mojibake in `ZentralGroupsDom.js`.
- New feature: **Notes** (`additional/notes/`, standalone-capable) with optional sidebar dock (`notes.dock_sidebar`).
- **Free numeric entry in Sine**: 103 numeric settings get a `<key>_text` field; `createNumericPrefSync` (in `loader/ZentralRuntime.js`, copied into every standalone bundle) keeps it in step with the real integer pref. Ranges widened (Look clamps in `ZentralAppearance.js`, schema `numeric` ranges via `tools/add-numeric-metadata.py`).
- RSS card is now a top-layer popover, so it renders above Big Preview. `z-heights_map.md` is generated by `tools/build-z-map.cjs`.
- Resize perf: floating drag reads geometry once per event; horizontal panel resize caches its limit; vertical resize applies once per frame; reveal-edge geometry coalesced on window resize.
- Bumped everything to 3.1.3. Standalone locks were reset to 3.1.2 and rebuilt (see "How to rebuild" below).

## 3. Audits that were planned but NOT run

- CSS attribute selectors that no JS ever sets, and JS-set attributes no CSS uses (dead CSS / dead flags).
- Duplicate element IDs across modules (`id = "..."`, `getElementById` targets created twice).
- Dead links and stale claims in `.github/README.md`, `additional/*/README.md`, `INSTALL.md` (check the Notes section, the numeric-entry description, links into gitignored `docs/`).
- Left/right resize handles clipped at the window's side edges (same bug class as the fixed top/bottom ones). Left alone on purpose: it only affects handle grab area, not blocking of the top bar.
- Position tracker (`zentral/apps/controllers/ZentralPanelPosition.js` `reposition` / rAF loop) may run `positionPanel()` up to three times per frame during window or sidebar resize. Not changed because it is timing-sensitive (must follow transform-only transitions). Profile in Zen first; add `performance.now()` sampling around drags.
- `onPanelOutsideWindowReturn` runs on every pointermove (cheap, but it bumps a generation counter that may guard async work; do not "optimize" without checking).
- Run the Zen Performance panel while dragging: panel resize, floating drag, Big Preview resize, Library resize.

## 5. How to verify and rebuild (Node only)

```text
node tools/organize-layout-order.cjs
python3 tools/add-numeric-metadata.py        # after changing any numeric setting or LOOK_RANGES
node tools/build-preferences.cjs             # writes preferences.json and loader/numeric-prefs.json
node tools/check-settings-consistency.cjs
node tools/build-z-map.cjs                   # regenerate z-heights_map.md
node tools/build-standalone.cjs              # refuses changed content without a version bump
node tools/build-standalone.cjs --check
for t in standalone notes notes-ui notes-bars numeric-prefs encoding z-heights resize-perf; do node tests/$t.test.cjs; done
```

Release-in-progress trick: 3.1.3 is unreleased, so after editing a bundled file the builder complains "content changed but version is still 3.1.3". Reset every `additional/**/standalone.lock.json` `"version"` to `"3.1.2"` (last published) and run `node tools/build-standalone.cjs` again. Do not hand-edit `.standalone.uc.js` files.

`tools/` and `docs/` are gitignored in this repo; they are included in the zip so nothing is lost.
