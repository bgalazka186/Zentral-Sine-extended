# Owner bug set — 2026-11-18 (version 3.4.0)

This report covers the four bugs reported together: missing Notes sidebar titles, grayscale Agenda favicons, resize jank with Notes in a Zentral panel / Triple View, and Boost's `3202756,6 GB` RAM reading. The repository has no live Zen/Sine runtime, so visual appearance and real frame rate remain an **OWNER GATE**; every claim below is pinned by Node tests, source checks or generated-build checks.

> Correction (`OW-119`, 2026-11-18): the owner rejected `04be3bae` because compact tabs broke. Its appended OW-116 rules overrode compact label clipping/icon visibility, and a duplicate `const docRoot` left the panels coordinator with a JavaScript `SyntaxError` that the earlier `279/279` suite did not parse. The compact-tabs files are restored byte-for-byte, the visual rules now live in Notes' own CSS, and all runtime scripts are syntax-guarded. This report supersedes the previous DONE/validation claim; live compact-tabs appearance is still an OWNER GATE.

> Diagnostic follow-up (`OW-120`, 2026-11-19): the owner supplied a 5.46 MB Browser Console JSON from the temporary `owner-sidebar-console-diagnostics.md` diagnostic (later deleted by the owner in `13755e4`). It was labelled `collapsed-broken` but `context.sidebarState` was `expanded`; the Notes root header was 12 px wide and centred, the note row was 26 px wide with a 0 px label container, and the Agenda row still had `opacity: 0.69` / `filter: grayscale(1)` because OW-116's CSS only matched `zen-folder[bgalazka-notes-folder]`. `docs/ow-120-owner-diagnosis.md` carries the exact numbers. OW-120 adds narrow Notes/Agenda-folder-scoped geometry and filter/opacity overrides; it does not change Zen's collapsed-sidebar behavior or ordinary compact tabs. Live visuals remain an OWNER GATE.
