# Owner bug set — 2026-11-18 (version 3.4.0)

This report covers the four bugs reported together: missing Notes sidebar titles, grayscale Agenda favicons, resize jank with Notes in a Zentral panel / Triple View, and Boost's `3202756,6 GB` RAM reading. The repository has no live Zen/Sine runtime, so visual appearance and real frame rate remain an **OWNER GATE**; every claim below is pinned by Node tests, source checks or generated-build checks.

| Ref | Defect and fix | Verification / limit |
| :-- | :-- | :-- |
| `OW-116` | Notes/Agenda pseudo-tabs are parked with `[pending]`. The browser can rewrite both the tab's `label` attribute and its native `.tab-label` node. Notes now writes/restores both roads on projection, relabel, discard healing and `TabAttrModified`; a narrow CSS override clears `filter`/`opacity` on the pending row, favicon and label and restores `visibility` on the label/icon nodes. It never uses `display: none`, zero width/height or zero font size, so it cannot repeat the missing-title regression. | `tests/ow-116-pending-placeholder-visuals.test.cjs` drives the real Notes source through the fake Zen browser and audits the shipped CSS. OWNER GATE: compare Notes/Agenda titles, folder labels, favicons, grayscale, opacity and spacing in live Zen with compact mode, a collapsed folder and the space indicator. Third-party Arc/Zen unloaded-tab styles may still need the owner's local preference check. |
| `OW-117` | Repeated resize notifications no longer rewrite an unchanged sheet: layout has a geometry/state fingerprint, rAF-driven observer passes are dedupable, direct state-changing layouts are still forced, and style/dataset writes are guarded. Floating-card settle work is one coalesced rAF plus one trailing timer instead of an unconditional 450 ms per-frame loop. `syncPanelPushState` writes changed attributes only; an unchanged Triple View slot returns before CSS writes/events, while the existing secondary geometry fit stays rAF/timer coalesced (its first reserve fit must remain synchronous so the panels are measured immediately). | `tests/ow-117-notes-resize-coalescing.test.cjs` proves 12 unchanged resize turns cause zero full layout/style/dataset writes in the fake panel world and pins the source contracts. Not measured: real compositor latency, Gecko layout, remote browsers and live top-bar/Triple View drag feel. OWNER GATE: resize the panel, squeeze it with the top bar, and use Triple View + Notes in live Zen. |
| `OW-118` | `ChromeUtils.requestProcInfo().memory` is bytes. Boost's meter now sums parent/child bytes and divides once by `1_000_000` before the widget's decimal MB/GB formatter; the async Promise path uses the same helper. Existing fake ProcInfo fixtures were changed from MB-like numbers to real bytes, so tests describe Gecko's contract rather than the old mistake. | `tests/ow-118-boost-procinfo-bytes.test.cjs` feeds `3,202,756,600` bytes and asserts `3203 MB` / `3.2 GB`; source, generated standalone, README and plan all name bytes. No live browser memory measurement is claimed. |
