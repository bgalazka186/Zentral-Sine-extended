# Screenshot plan — Zentral Extended README

Images live in `assets/` and are referenced from `.github/README.md` as `../assets/<file>`.
Prefer static PNG screenshots over videos. Keep each capture tight on the single UI it demonstrates — no backgrounds, no multiple features in one frame. 1080p or higher, Zen in light theme unless the feature is dark-mode specific. Hide personal URLs and account info.

### Mods used in screenshots

Screenshots are captured with these other Sine mods installed alongside Extended: Zen Folder Tree Connectors, Transparent Zen, Customize Font Size, Arc 2.0, better-ctrl-tab, ZenLibraryTweaks and Tab Groups. Some UI elements visible in captures may come from those mods rather than from Extended itself.

Naming convention: `zentral-<section>-<feature>.png`, all lowercase, no spaces.

## Layout format

Each feature image is centered directly under its bold feature label at `width="420"`. No floating right-align — text and image stay together so it’s clear which screenshot belongs to which feature.
