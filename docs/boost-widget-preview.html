Boost widget: narrow sidebar preview

This static page loads the shipped ZentralBoostWidget.css and the same one-shot contrast helper used by the card. Each theme shows 140, 146, 170, 220, 300 and 360 CSS-pixel host widths; the 146 px narrow check uses a readable 2×2 fallback, while the outlined 170 px target has enough content for one compact row. The actions use 24 px targets, and Restore's count badge must stay inside its button. The separate custom-colors sample shows a Boost card mirroring the existing Widgets appearance override. The deliberately bad theme should gain the luminance-matched forced palette automatically.
