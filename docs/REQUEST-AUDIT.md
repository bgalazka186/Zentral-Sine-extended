## Current enlarged-video request

No top bar. Return and Fullscreen join the existing bottom controls. Drag anywhere on the video image to move; all four edges and four corners resize. Size and position persist separately from the sidebar. The first/default video area is 1280×720, scaled down to fit the window, anchored to the bottom corner on the sidebar's side. The former untouched 640×420 default migrates; other remembered sizes remain. Four quick clicks can enlarge then return because movement must cross a real dead zone before click suppression applies.

Fullscreen uses Zen's window-fullscreen mode plus a viewport-filling preview. Escape first exits preview fullscreen and then, on another press, returns to the sidebar. A fullscreen window the user already owned is not switched out of fullscreen when the preview closes. Fullscreen does not overwrite remembered geometry. This is still an in-browser floating preview, not a separate OS Picture-in-Picture window.

Compact hiding remains independent of an enlarged card. Supported atomic whole-card placement handles display:none ancestors; the guarded fallback is top-layer-only on older runtimes. No second source stream is created.
